## 📌 Executive Summary & Curriculum Scope

"Data Analysis with R Programming" is the 7th course in the Google Data Analytics Professional Certificate curriculum. It equips data analysts with foundational programming skills in R, covering the `tidyverse` ecosystem, tabular data transformation with `dplyr`, grammar of graphics data visualization with `ggplot2`, and reproducible reporting using R Markdown.

The course encompasses **5 Modules** spanning **118 individual learning items**:

```
Google Data Analytics: Course 7 Map
├── Module 1: Programming and Data Analytics
│   ├── R & RStudio environment setup, console, scripts, CRAN
│   ├── Variables, data types, vectors, lists, data frames, matrices
│   ├── Operators (arithmetic, relational, logical) & tidyverse installation
│   └── Graded Assessment: Module 1 Challenge (100.00%)
│
├── Module 2: All About Data in R
│   ├── Data structures: Tibbles vs. standard data frames
│   ├── Reading data: readr, readxl, CSV import
│   ├── Inspecting data: str(), glimpse(), head(), colnames()
│   ├── Pipe operator (%>%) mechanics and chaining
│   └── Graded Assessment: Module 2 Challenge (100.00%)
│
├── Module 3: Working with Data in R
│   ├── Cleaning and transforming with dplyr
│   ├── filter(), select(), mutate(), arrange(), rename()
│   ├── Grouping and summarizing: group_by(), summarize()
│   ├── Handling missing data: is.na(), drop_na()
│   ├── Pivoting data: pivot_longer(), pivot_wider()
│   └── Graded Assessment: Module 3 Challenge (100.00%)
│
├── Module 4: More About Visualizations, Aesthetics, and Annotations

│   ├── Aesthetic mappings: aes(x, y, color, size, shape, fill)
│   ├── Geometric layers: geom_point(), geom_bar(), geom_line(), geom_smooth()

│   └── Graded Assessment: Module 4 Challenge (100.00%)
│
└── Module 5: Documentation and Reports (R Markdown)
    ├── Reproducible research principles
    ├── R Markdown syntax, YAML header, code chunks ({r echo=FALSE, message=FALSE})
    ├── Knitr engine and output rendering (HTML, PDF, Word)
    ├── Integrating inline code calculations
    ├── Graded Assessment: Module 5 Challenge (100.00%)
```
