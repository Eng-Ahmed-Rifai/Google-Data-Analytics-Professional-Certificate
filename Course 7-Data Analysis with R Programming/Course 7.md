## Course Overview
This course explores the fundamentals of the R programming language, covering data manipulation, transformation, and visualization techniques essential for professional data analysis.

### Core Modules & Topics Covered:
1. **Programming and Data Analytics:** Fundamentals of R, RStudio environment, variable assignments, vectors, lists, data frames, pipes (`%>%`), and package management (`tidyverse`).
2. **All About Data in R:** Loading external CSV files, reading tabular data, inspecting structure (`str()`, `glimpse()`, `head()`), data types, and logical operations.
3. **Working with Data in R:** Data transformation with `dplyr` (`filter()`, `select()`, `mutate()`, `arrange()`, `group_by()`, `summarize()`), handling missing values, and data cleaning.
4. **Visualizations, Aesthetics, and Annotations in R:** The Grammar of Graphics with `ggplot2` (`geom_point()`, `geom_bar()`, `geom_line()`, `facet_wrap()`, aesthetic mappings, color palettes, titles, labels, and themes).
5. **Documentation and Reports with R Markdown:** Reproducible data analysis using R Markdown (`.Rmd`), code chunks, rendering to HTML/PDF, and sharing reproducible research.
