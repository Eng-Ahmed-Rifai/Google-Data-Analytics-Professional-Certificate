## 🔍 Core Competencies Covered
- **Python for Analytics**: Variable scopes, functions, list comprehensions, and data transformations.
- **Data Manipulation with Pandas**: Reading CSV/JSON files, indexing, boolean filtering, group-by aggregations, joining/merging datasets, and handling missing/null values.
- **Numerical Operations with NumPy**: Array manipulation, vectorization, mathematical broadcasting, and statistical summaries.
- **Exploratory Data Visualization**: Creating charts and diagnostic plots using `matplotlib` and `seaborn` to extract actionable business insights.
