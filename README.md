## 📚 Complete Program Curriculum (9 Course Series Breakdown)

| Course # | Course Title | Core Analytics Tools & Learning Outcomes |
| :---: | :--- | :--- |
| **01** | **Foundations: Data, Data, Everywhere** | Data Analyst Ecosystem, Analytical Thinking, Data Life Cycle, Spreadsheet & Database Fundamentals |
| **02** | **Ask Questions to Make Data-Driven Decisions** | Business Problem Framing, Stakeholder Communication, SMART Questions, Structured Problem Solving |
| **03** | **Prepare Data for Exploration** | Data Sourcing, Data Ethics & Privacy, SQL Database Schema Design, Database Normalization & Indexing |
| **04** | **Process Data from Dirty to Clean** | Data Integrity Verification, Data Cleaning in SQL & Spreadsheets, STRING Manipulation, Missing Data Imputation |
| **05** | **Analyze Data to Answer Questions** | Google BigQuery SQL Aggregations, JOINs, Subqueries, CTEs, Window Functions & Calculations |
| **06** | **Share Data Through the Art of Visualization** | Tableau Dashboard Design, Data Storytelling, Interactive Charts, Color Theory & Executive Presentations |
| **07** | **Data Analysis with R Programming** | RStudio, tidyverse Data Wrangling, ggplot2 Visualizations, R Markdown Dynamic Reporting |
| **08** | **Google Data Analytics Capstone Project** | End-to-End Case Study (Cyclistic Bike-Share Analytics), Data Wrangling, Insights & Strategic Recommendations |
| **09** | **Analytics Career Preparation & Technical Portfolio** | Technical Portfolio Case Study Packaging, SQL & R Code Auditing, Business Communication |

## 🛠️ Key Skills & Analytics Stack

- **SQL Data Manipulation**: Complex SQL queries, CTEs, window functions, aggregations, and JOINs in Google BigQuery.
- **R Programming**: Exploratory Data Analysis (EDA), tidyverse (dplyr, tidyr, readr), and ggplot2 data visualizations.
- **Data Visualization & Storytelling**: Interactive executive dashboards and KPI dashboards built in **Tableau**.
- **Data Cleaning & Governance**: Data integrity validation, anomaly detection, missing data handling, data ethics & compliance.
